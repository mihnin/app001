# Skuratov Coffee — учебное веб-приложение предзаказа

Учебный прототип по документам из `docs/` (бизнес-постановка v2.0, ТЗ v0.1). Гость выбирает напитки,
пожелание и интервал получения; сотрудник ведёт заказ по очереди до выдачи. Меню, цены и адрес
демонстрационные: реальных заказов и оплаты нет.

Стек и принятые решения по открытым вопросам: [docs/STACK.md](docs/STACK.md).

## Запуск

```bash
pip install -r requirements.txt
python -m app.cli run                 # http://127.0.0.1:8000  (гость)
                                      # http://127.0.0.1:8000/staff (сотрудник, пароль: barista)
```

Переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `STAFF_PASSWORD` | `barista` | пароль панели сотрудника (смените для показа) |
| `APP_DB` | `data/app.db` | файл SQLite |
| `APP_TZ` | `Europe/Moscow` | часовой пояс точки |
| `APP_NOW` | — | тестовое время, напр. `2026-09-29T10:00`: часы стартуют с него и идут дальше |

Сброс демонстрации (только автор, с доступом к серверу):

```bash
python -m app.cli reset --yes
```

## Тесты

```bash
python -m pytest
```

- `tests/unit` — доменная логика: статусы, цена, пожелание, интервалы, сводка;
- `tests/services` — приём, идемпотентность, гонка за последнее место, откат при сбое, отмена, закрытие дня;
- `tests/api` — сквозные сценарии ПИ-01…ПИ-12 через HTTP (два гостя и сотрудник).

## Структура

```
app/domain     бизнес-правила без БД и HTTP
app/db         SQLite: схема, соединение, демо-набор
app/services   сценарии в транзакциях
app/api        маршруты, доступ, формат ошибок
app/static     интерфейсы гостя и сотрудника (HTML/CSS/JS)
app/cli.py     запуск и сброс
```

Ни один файл не длиннее 500 строк.
